# enterprise-ai-app
企业级 AI 应用开发实战 | 包含大模型 API、RAG、Agent、Coze/Dify 项目

## 技术栈
- 编程语言:Python 3.10+
- 大模型:字节跳动豆包
- 低代码平台:Coze、Dify
- 部署:Docker

## 项目结构
enterprise-ai-app/
├── src/ # 源代码
├── configs/ # 配置文件
├── tests/ # 单元测试
├── docs/ # 文档
└── requirements.txt #依赖管理文件


## 快速开始
1. 克隆仓库
2. 安装依赖：`pip install -r requirements.txt`
3. 复制 `configs/dev.yaml` 并填写你的AK/SK
4. 运行项目
